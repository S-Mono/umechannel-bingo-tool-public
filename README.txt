============================================================
spacha-bingo v1.1.0 - うめちゃんねる専用スパチャビンゴ抽選ツール
============================================================

本ソフトウェアをご利用いただきありがとうございます。
本ツールは、配信画面の邪魔をせず、かつ公平な抽選を可能にするために
設計された、軽量・ポータブルなビンゴ管理システムです。

------------------------------------------------------------
■ 導入方法（インストール不要）
------------------------------------------------------------
1. ダウンロードしたZIPファイルを任意のフォルダに解凍してください。
2. フォルダ内の「spacha-bingo.exe」を実行してください。
   ※「WindowsによってPCが保護されました」と表示される場合は、
     「詳細情報」→「実行」を選択してください。

------------------------------------------------------------
■ データの保存場所について
------------------------------------------------------------
本アプリはポータブル仕様です。
以下のデータは、すべて実行ファイル（.exe）と同じフォルダに保存されます。

※！これらのファイルは削除しないようご注意ください！

・bingo_config.json : ウィンドウ位置、音量、TTS（数字読み）設定
・logs/             : システム実行ログ（最新50件を保持）
・sessions/         : 過去のビンゴ当選履歴（過去ログ）

また、ビンゴ演出用の動画素材を使用する場合は、実行ファイルと同じ階層に
「effects」フォルダを配置し、その中に動画ファイルを格納してください。

・effects/normal_bingo.mp4 : ビンゴ達成時の通常演出
・effects/special_1.mp4    : 1用の特殊演出
・effects/special_25.mp4   : 25用の特殊演出

※ 動画ファイルが存在しない場合、該当演出はスキップされるか、
　 通常ビンゴ演出を再生するようにしています。

フォルダごと移動・コピーするだけで、別のPCやフォルダへ移行できます。
バックアップする場合もアプリがあるフォルダごとコピーすることをおすすめします。

------------------------------------------------------------
■ 不具合・お問い合わせについて
------------------------------------------------------------
動作に異常がある場合は、同フォルダ内の「logs」フォルダに含まれる
最新のログファイルを添えて、開発者までご連絡ください。
