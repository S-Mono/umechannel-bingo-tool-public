BingoTool v1.0.0 - うめちゃんねる専用スパチャビンゴ抽選ツール
============================================================

本ソフトウェアをご利用いただきありがとうございます。
本ツールは、配信画面の邪魔をせず、かつ公平な抽選を可能にするために
設計された、軽量・ポータブルなビンゴ管理システムです。

------------------------------------------------------------
■ 導入方法（インストール不要）
------------------------------------------------------------
1. ダウンロードしたZIPファイルを任意のフォルダに解凍してください。
2. フォルダ内の「BingoTool.exe」を実行してください。
   ※「WindowsによってPCが保護されました」と表示される場合は、
     「詳細情報」→「実行」を選択してください。

------------------------------------------------------------
■ データの保存場所について
------------------------------------------------------------
本アプリは「真のポータブル」仕様です。
以下のデータは、すべて実行ファイル（.exe）と同じフォルダに保存されます。

※！これらのファイルは削除しないようご注意ください！

・bingo_config.json : ウィンドウ位置、音量、TTS設定
・logs/             : システム実行ログ（最新50件を保持）
・sessions/         : 過去のビンゴ当選履歴（過去ログ）

フォルダごと移動・コピーするだけで、環境をそのまま移行できます。

------------------------------------------------------------
■ 不具合・お問い合わせについて
------------------------------------------------------------
動作に異常がある場合は、同フォルダ内の「logs」フォルダに含まれる
最新のログファイルを添えて、開発者までご連絡ください。
